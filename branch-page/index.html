Overview

Each chart compares this branch against main on one architecture. Each point is a crate's total wall time under BorrowSanitizer's full configuration: the sum of its tests' mean execution times, in seconds, on a log scale. Each benchmark run of the branch is its own line, in a color of its own, so a rerun adds a line rather than replacing one; the most recent runs are kept. When the list of benchmarked crates changes, the chart starts over.

Only tests that succeeded on both main and the branch are counted. Everything left out is listed under Excluded tests with its result on each side, so a test the branch broke (or fixed) is identifiable.

Main's numbers come from its most recent benchmark run when one covers the crate, and are measured alongside the branch otherwise. They can come from different runners, so treat differences of a few percent as noise.
