Overview

This is a one-off measurement of a branch, not a history. Each point is a crate's total wall time under one configuration — the sum of its tests' mean execution times, in seconds, on a log scale.

Only tests that every configuration ran with the same result are counted. A configuration that loses tests would otherwise be credited with less work and look faster for it. Everything left out is listed under Excluded tests, with each configuration's result, so a test that fails only under instrumentation is visible rather than silently missing.

Times are raw sums with nothing subtracted. Each measurement runs a test binary directly with an --exact filter, so there is no per-invocation cargo overhead to remove.
